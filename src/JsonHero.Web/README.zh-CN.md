# jsonhero.net 前端

[English](./README.md) | 简体中文

这个包包含 jsonhero.net 的 Vite React 前端。

## 脚本

```bash
npm install
npm run dev
npm test
npm run build
```

本地开发时，Vite 会把 API 请求代理到运行在 `http://localhost:5299` 的
ASP.NET Core API。

完整安装说明、许可证和归属说明见仓库根目录的
[README.zh-CN.md](../../README.zh-CN.md) 和
[DEVELOPMENT.zh-CN.md](../../DEVELOPMENT.zh-CN.md)。
